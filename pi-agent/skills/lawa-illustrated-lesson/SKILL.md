# 图解讲页

想象和学习者共读一页书。挑出一个值得用眼睛观察的细节，自己选题材、比喻、构图和行文。画面可以是物件、人物、自然插画或精确示意。静态插画本身就可以完成一次讲解。学习者想自己试一个条件时，用可调示意。需要跟着老师看一件事怎样发生时，安排对象在时间中动作，让每段字幕解释此刻可见的原因或结果。读者点一次播放即可看完整段。用 `prepare_lesson_figures(require_motion=true, figures=[…])` 制作这种讲解动画，时间与字幕写进 `motion`。画法见[时间与动作](references/motion.md)。工具回执里的类型说明读者实际能看到什么。

默认让学习者连续观看，随时暂停提问。已经给过推理线索、下一步尚未揭晓，并且不同预测值得用不同画面回应时，可以安排一次可跳过的[画中预测](references/prediction.md)。读者选的位置会保留作比较，也可回看刚才的动作。前文、标题、替代文字和停下时的画面只铺垫线索。

人物、环境、器物和叙事情境可以画成精致书籍插画。给百炼的画稿只需 `{"key":"evening","alt":"傍晚小路上的路灯和木桩","caption":"沿着光照方向观察地面。","paint":"黄昏小路的横幅书籍插画。路灯在左，矮木桩在右，影子向右延伸。钢笔线描与透明水彩，温暖纸纹。"}`。画面描述用肯定句写眼前的主体、环境、光线与构图。把数值、刻度和图解要求留给另画的精确示意。每轮可委托一幅，图片在后台完成。可以同批再准备几何示意，正文照常展开。图像出处随成图保存。

在课堂中先用 `prepare_lesson_figures` 一次准备本轮所需的图。工具返回可直接使用的 Markdown 图址。时间动画作为最后一批教学操作时，整批成功保存后课堂直接进入公开讲解。若还要准备习题等操作，在制动画时加 `keep_preparing:true`。其他画稿沿用 `begin_teacher_reply` 开始讲解。把图址单独放在引用这幅图的两段文字之间，前后各空一行。前文给读者一个观察理由，后文用图中能看到的具体细节继续推理。沿用课堂正常的流式回复。学习者明确只想看文字时直接讲。

**画法**　`view:[宽,高]` 是画纸。`ink` 中每一笔用 `[SVG形状,属性]` 表示，可用 path、line、rect、circle、ellipse、polygon、polyline 和 text。形状按从后到前的顺序绘制。text 的第三项是短标签。长说明写在正文或图注，能随页面换行。颜色用十六进制或 ink、paper、leaf、water、clay、muted、none。

一个静态小例子。弦贴着弧的两个端点，读者能直接看见两条路径的差别。

```json
{"key":"chord","alt":"一条弧和它两个端点之间的直线","caption":"弦和弧共享两个端点。","view":[240,110],"ink":[["path",{"d":"M 26 84 Q 120 -40 214 84","fill":"none","stroke":"water","stroke-width":3}],["line",{"x1":26,"y1":84,"x2":214,"y2":84,"stroke":"ink","stroke-width":2}]]}
```

填写 alt 和图注。课堂自画示例可注明示意；依据已有资料时写实际出处。定量图先核对两个端点和一个中间值。在写结论的那一段说明使用的单位、参照与假设，让读者知道结论适用于什么情况。动画定住了哪些条件，正文的推论也要带上这些条件。给读者讲清眼前的问题就可以收笔。需要百炼画稿和导出说明时见[书籍插画](references/painting.md)。需要连续图或更多绘制细节时再读[画法与变量](references/drawing.md)。图内的操作只用于观察。

独立导出时，保存 `{"body":"带图址的课堂正文","figures":[…]}`，运行 `node scripts/export.mjs lesson.json lesson.html`。含百炼成图时在命令末尾加本地 PNG 目录。独立页面和 LaWa 使用同一份画稿。
