# 书籍插画

在 LaWa 中向 prepare_lesson_figures 交一份 paint 描述、图址 key、alt 和图注。场景中的物件、人物的动作、观察视角与相对位置决定画面是否有教学价值。可以选择水彩、钢笔、石墨、版画或其他适合这节课的媒介。描述只包含绘画所需信息。

百炼在后台绘制横幅图。收到图址即可开始正文，页面会在原位显示进度和成品。每个真实用户回合可委托一幅生图，可以同时安排其他精确示意。已有委托会复用。课堂打开或刷新只读取本地副本。

把事实、单位和图注写在图外。生成图适合把读者带进一个情境。对于具体的受力方向、图中物体数目等需要精确核对的内容，可配合原文来源或可计算图。老师在实际看过成图前，只介绍观察任务与已知条件。

在 LaWa 中直接复用已保存的百炼档案。独立创作时可以用 Node 22 或更新版本执行以下命令。

1. 将上文的四字段画稿保存为 `brief.json`。在当前进程配置 `DASHSCOPE_API_KEY`，需要工作空间专属域名时再配置 `DASHSCOPE_BASE_URL`。
2. 执行 `node scripts/bailian.mjs --generate brief.json art-dir` 委托一次生图。命令显示本地画稿引用文件的路径。在页面 JSON 的 `figures` 数组中放入该文件的内容。相同画稿再次使用已有成图。发生中断时保留请求标记，先在百炼核对该次请求。
3. 在正文段落间写入对应图址。执行 `node scripts/export.mjs page.json page.html art-dir`，成品 HTML 内嵌 PNG 和交互图，离线打开即可阅读。

分享成品 HTML 即可。凭证留在创作端。

服务协议参见[阿里云百炼千问图像文生图文档](https://help.aliyun.com/zh/model-studio/qwen-image-api)。
