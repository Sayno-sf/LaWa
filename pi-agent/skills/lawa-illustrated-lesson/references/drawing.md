# 画法与变量

画纸原点在左上。`view` 给出 96–1000 的宽与 64–640 的高，页面等比显示。静态图可以画完全自由的 SVG path 曲线。绘画用本地图形数据。通用属性有 fill、stroke、stroke-width、opacity、stroke-linecap、stroke-linejoin、stroke-dasharray 和 fill-rule。text 还接受 text-anchor 与 font-size；最多 16 个字符。图片说明和图外读数始终跟随正文排版。

需要观察连续变化时，给图添加 `axis:{"label":"宽","min":2,"max":6,"unit":"米","readings":[{"label":"面积","expr":"x*(12-x)","unit":"平方米"}]}`。x 是滑块读数本身。可变数值属性以等号开头，例如 `width:"=(12-x)*22"`、`height:"=x*22"`。表达式支持十进制数、x、四则运算和括号。path 的轨迹和 text 的文字固定；把变化放在圆心、半轴、端点、矩形尺寸或透明度。图形、读数、播放和停帧取自同一个 x。

画一把回形针可以用一根弯曲的 path。画一场比较，可以给两个对象相同的基线。让学习者看到因变量时，指出哪些条件固定。允许同一页有几幅性质迥异的插画，每幅可核对自己的出处。图址形式为 `![简短替代说明](lawa-figure:图的key)`，置于普通段落之间。把图上必须阅读的长句移至图注。

每幅最多 96 笔，最多 4 个图外读数。key 用小写英文字母、数字和连字符，字母起首。一批 1–4 幅。一次讲解可完整地停在一幅静态插图；读者可对该图提问。图注中的反事实、假设与实测结果应有明确区分。
