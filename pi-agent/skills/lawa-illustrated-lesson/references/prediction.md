# 画中预测

先让读者看完一个有用的例子或一段完整动作。选一个可以指给老师看的问题，停在结果出现之前。读者点的位置会留下一个空心圈，画稿随后演出实际结果。只有一个预测点，可选 2–3 个有意义的位置。直接点「继续看」沿原时间线播放。学习者需要连续观看时使用普通 motion。

在画稿顶层与 `motion` 并列写 `prediction`。明确需要这种交互时，调用 `prepare_lesson_figures` 可带 `require_prediction:true`。例如在小车过弯演示中已经安排好 5 段动作，第 3 段把车推到分岔口，第 4 段实际沿上方轨道前进。以下坐标须与实际画纸和轨道终点一致。

```json
{"after":3,"through":4,"prompt":"按车轮现在对准的轨道，它会经过哪里？","options":[{"id":"upper","label":"上方轨道","point":[240,55],"feedback":"看车轮怎样沿轨道走向你标的位置。"},{"id":"lower","label":"下方轨道","point":[240,115],"feedback":"空心圈是你的落点。再看车轮入岔时对准哪条轨道，然后比较两处。","replay":true}]}
```

`after` 是刚演完的段号，从 1 开始。`through` 是保留预测标记和反馈的最后一段，默认下一段。期间应当实际演出预测对象的去向。每个选项用一句话说明接下来该看哪里。`replay:true` 回放预测前最近一段实际运动，接着演出结果。把 `after` 放在给足线索的动作末尾，播放器负责停下和显示问题。正常选项直接演出结果。热点位于画稿坐标内，留出容易点击的间距。

组织整页时，先给一条可以迁移的线索，再让读者把它用到一个新位置或新对象上。若选项照抄刚说过的定义，改用能追踪的具体对象，或让这段连续播完。类比里的操作限制要说清，例如约定只从顶端取书。标题、图前正文、alt、第一帧和预测前的字幕都应保留悬念。用停帧的真实位置措辞。例如物体刚到门口，就问接下来会到哪里。让各个选项平等呈现，说明空心圈的含义，猜偏时让读者比较自己的位置与真实结果。预测只用于调整讲法，正式作答沿用课堂题卡。
